# Repaso ASI — Cuestionarios y Parciales

App web de repaso para ASI: cuestionarios de teoría y preguntas de parciales, con
corrección inmediata y puntaje acumulado.

## Uso

Abrí `index.html` en cualquier navegador. No requiere instalación, build ni servidor.

## Stack

- HTML, CSS y JavaScript vanilla en un único archivo autocontenido
- Imágenes embebidas en base64 (sin archivos externos)
- Tipografías Archivo e Inter vía Google Fonts

La única dependencia de red son las fuentes; sin conexión la app funciona igual, con
tipografías del sistema.
